Privacy Policy

Last Updated: August 2026

1. Data We Collect

To deliver moderation logs, warning tracking, and Spotify features, the Bot processes the following data:

  • Discord IDs: User IDs, Server (Guild) IDs, and Channel IDs to associate warnings and permissions correctly.
  • Usernames & Avatars: Used to display public moderation actions and member profiles within Discord embeds.
  • Spotify Activity Data: When using music features (e.g., !listening), the Bot temporarily reads publicly shared Spotify Rich Presence status provided by Discord.

2. How We Use Data

Data collected is strictly utilized to enable core bot functionality—such as keeping track of member warnings and providing music search results. We do not sell, rent, or share your data with third parties.

3. Third-Party Services

This Bot interacts with the Spotify Web API to fetch track links and recommendations. Usage of Spotify-related commands adheres to Spotify's public developer terms. No personal Spotify credentials (passwords/tokens) are ever requested or collected from users.

4. Data Retention & Deletion

Temporary moderation logs (like active warning lists) are held in operational memory. Server administrators can clear warnings at any time. If you wish to request full data deletion for your server or account, please contact the bot developer or remove the Bot from your server.
